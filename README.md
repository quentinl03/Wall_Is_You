# Wall_Is_You

## Description

Wall-Is-You is the final project for first year students in the University Gustave Eiffel of 2022-2023. 
The goal of this project is to create a maze game and implement different solving algorithms.

## Installation / Usage

```bash
git clone https://github.com/quentinl03/Wall_Is_You
cd Wall_Is_You
python3 main.py maps/...
```

## Goals

Wall Is You is a reinterpretation of the classic scenario in which the player takes on the role of a courageous adventurer and must enter a sinister dungeon to defeat the evil creatures within. In Wall Is You, the roles are reversed: the player takes on the role of a kindly dungeon who must help a particularly stupid adventurer to rid it of the monsters that live there.


You can rotate the dungeon rooms by left-clicking on them.
You can also place / remove treasures to lure the adventurer by left-clicking.
By default, the adventurer is attracted by the highest level monster.


## Controls
 - Right click : Place a treasure
 - Left click : Rotate a room
 - Space : follow the showing path
